# Medical Research Agent

A specialized AI system that automates the analysis of clinical research papers by dynamically leveraging multiple large language models (LLMs) through Lilypad’s decentralized network. It identifies relevant studies, extracts precise medical data (treatment protocols, efficacy rates, adverse effects), and synthesizes clinician-ready reports, all while intelligently routing tasks to the optimal LLM (DeepSeek for technical depth, Qwen for multilingual support, Llama for general synthesis) without exposing the model selection process.

▸ **📌 Core Functions**  
- **🔍 Smart Paper Discovery**  
  Locates relevant studies based on treatment types, trial phases, or patient groups  

- **📑 Key Data Extraction**  
  Isolates:  
  • Treatment protocols  
  • Efficacy metrics  
  • Adverse effects  

- **📝 Adaptive Reporting**  
  Generates:  
  → Technical summaries (for research teams)  
  → Plain-language versions (for patient education)
